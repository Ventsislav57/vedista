# Vedista

Представителен сайт на **Vedista** — компания за търговия, съхранение и логистика
на зърнени култури (пшеница, царевица, слънчоглед, ечемик, рапица).

Изграден с **Next.js 16 (App Router)**, **Tailwind CSS v4** и **Framer Motion**.
Всичко е статично — няма бекенд. Формата за контакт е демонстрационна
(`components/ContactForm.jsx` — тук по-късно се закача изпращане по имейл/API).

## Стартиране

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # продукционен билд (изцяло статичен)
npm start
```

## Структура

| Път | Съдържание |
| --- | --- |
| `app/page.jsx` | Начална страница (hero, дейности, култури, процес, отзиви, новини) |
| `app/za-nas` | За компанията, история, екип |
| `app/deynosti` | Подробно описание на услугите |
| `app/kulturi` | Спецификации по култури |
| `app/ustoychivost` | Устойчиво земеделие и ангажименти |
| `app/novini` | Новини и пазарни коментари (статични) |
| `app/kontakti` | Контакти + форма за запитване |
| `lib/site.js` | Централно съдържание — навигация, услуги, култури, статистики, отзиви |
| `components/` | Navbar, Footer, Hero, CropShowcase, Testimonials, Reveal, Counter и др. |

## Съдържание и изображения

- Текстовете и числата в `lib/site.js` са примерни — заменят се с реални данни на клиента.
- Снимките се зареждат от Unsplash (`next.config.mjs → images.remotePatterns`).
  За продукция се препоръчва да се свалят локално в `public/`.
- Илюстрациите на културите (`components/CropArt.jsx`) са SVG — без външна зависимост.
